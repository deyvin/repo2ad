# 005: Ruby 3.4.13 no lugar do 3.4.6

Data: 2026-11-24. Afeta: §3.1 (continua "Ruby 3.4").

## Contexto
Na T1, o brakeman acusou 1 warning de severidade alta, a CVE-2026-132825, no Ruby 3.4.6, com correção a partir do 3.4.13.
O 3.4.6 veio do Cabide, não de uma exigência do produto.

## Decisão
Subir para o **Ruby 3.4.13** (patch da mesma série, disponível no mise e na imagem oficial `ruby:3.4.13`):
`.ruby-version`, `ARG RUBY_VERSION` do `Dockerfile` e do `Dockerfile.dev`, e o Ruby do host via mise.
O aceite é o brakeman sem warnings, além dos testes verdes no container. O Cabide não muda.
